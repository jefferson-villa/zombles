      How to play

      Name the Black Ops or Black Ops II Zombies map in 5 guesses.

      • You start zoomed way in. Each wrong guess zooms out.
      • Pick a map from the list. Nicknames like Green Run or Alcatraz work too.
      • After 2 wrong guesses you get told which game it's from.
      • Daily is the same puzzle for everyone and resets at local midnight. Endless keeps going.
